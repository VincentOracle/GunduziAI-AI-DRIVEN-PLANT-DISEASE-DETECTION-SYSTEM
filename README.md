**Installation Instructions:**  
1. **Prerequisites:**  
   - Python 3.8+  
   - PostgreSQL 14+  
   - TensorFlow 2.10+, Flask, OpenCV, Firebase SDK  
   - GPU (for model training; optional for deployment)  

2. **Setup:**  
   - Clone the repository:  
     ```  
     git clone https://github.com/VincentOracle/GunduziAI-AI-DRIVEN-PLANT-DISEASE-DETECTION-SYSTEM.git  
     ```  
   - Install dependencies:  
     ```  
     pip install -r requirements.txt  
     ```  
   - Configure PostgreSQL database (update `config.py` with credentials).  
   - Run the Flask backend:  
     ```  
     python app.py  
     ```  
   - Access the web interface at `http://localhost:5000`.  

3. **Demo Access:**  
   - Pre-trained models are included in `/models`.  
   - Sample datasets are in `/data`.
